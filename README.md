# 📊 Data_Science_Capstone_Project

### 🎓 Capstone Project | Data Science & Machine Learning

> An end-to-end Machine Learning project to analyze customer behavior and predict customer churn using the Telco Customer Churn dataset.

---

## 🔍 Project Overview

Customer churn is an important business problem where companies try to identify customers who are likely to leave their services.

In this project, I explored customer data, performed data preprocessing and analysis, and built Machine Learning models to predict whether a customer will **Churn (Yes)** or **Stay (No)**.

---

## 🎯 Project Objectives

- Understand the Telco Customer Churn dataset
- Perform Exploratory Data Analysis (EDA)
- Identify and handle missing values
- Analyze customer churn patterns
- Study customer tenure and monthly charges
- Prepare data for Machine Learning
- Build and compare classification models
- Evaluate model performance

---

## 📌 Key Analysis

**Dataset & EDA**
- Dataset structure, columns & data types
- Descriptive statistics
- Missing value analysis
- Customer churn distribution
- Customer tenure distribution
- Monthly Charges vs. Churn analysis

**Data Preprocessing**
- Data type correction
- Missing value handling
- Categorical encoding
- Numerical feature scaling
- Feature preparation

---

## 🤖 Machine Learning Models

| Model | Purpose |

---

## 📈 Model Evaluation

The models are evaluated using:

- **Accuracy**
- **Precision**
- **Recall**
- **Confusion Matrix**
- **Classification Report**

> For churn prediction, Recall is especially important because identifying customers who are likely to leave can help businesses take preventive action.

## 💡 Key Insights

- Customer churn is influenced by factors such as tenure and monthly charges.
- Customers with shorter tenure are more likely to churn.
- Higher monthly charges can be associated with increased churn risk.
- Data preprocessing and feature scaling improved the quality of data for Machine Learning.
- Logistic Regression and Decision Tree were used to classify customers based on churn.
- Recall is an important metric for churn prediction because identifying potential churners helps businesses take proactive action.

- ## 📝 Conclusion

This project demonstrates how Data Analysis and Machine Learning can be used to understand customer churn and predict customers who are likely to leave.

The analysis helped identify important customer behavior patterns, while classification models provided a way to predict churn. These insights can help businesses take proactive steps to improve customer retention and reduce churn.
